## Q

A rectangle is 7.5 units wide and 4 units tall. Write Python code that stores the width and the height in two variables, computes the area and the perimeter in two more variables, and prints both.

[[BLANK height=170]]

[[KEY]]
Sample solution:

```python
width = 7.5
height = 4
area = width * height
perimeter = 2 * (width + height)
print("Area:", area)
print("Perimeter:", perimeter)
```
