ACTIVITY 7.1.1: Plotting Projectile Height (Lab 7.1) 0 / 20

A ball is thrown straight upward with initial velocity v0 (in m/s). Ignoring air resistance, its height above the ground at time t (in seconds) is given by:

h(t) = v0 * t - 0.5 * g * t ** 2

where g = 9.8 (the acceleration of gravity, in m/s²). In this exercise you will use NumPy to compute the ball's height over its whole flight, and Matplotlib to plot it.

First, download this template and rename it plot_projectile.py:

  • template.py (replace with your course's actual template link)
  1. Import the numpy and matplotlib.pyplot libraries (already included in the template).
  2. Prompt for and read the initial velocity v0 as a float, in m/s.
  3. Compute the total flight time t_total — the moment the ball returns to height 0 — using t_total = 2 * v0 / g.
  4. Create a NumPy array t of 100 evenly spaced time values from 0 to t_total, using np.linspace.
  5. Compute an array h holding the height at each value in t, using the formula above (applied to the whole array at once — no loop needed).
  6. Plot h versus t with plt.plot(t, h).
  7. Label the x-axis "Time (s)", the y-axis "Height (m)", and set the title to "Projectile Height".
  8. Turn on the grid with plt.grid(True), then call plt.show().
