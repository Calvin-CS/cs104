Write a program that uses NumPy to convert a list of Celsius temperatures to Fahrenheit, all at once — with no explicit loop over the values.

  1. Prompt for and read a comma-separated list of Celsius temperatures from the user as a single line of text, e.g. 0,20,37,100.
  2. Split the input on commas and convert each piece to a float, storing the results in a NumPy array called celsius. (You may build a plain Python list first with float(x) for each piece, then pass it to np.array(...).)
  3. Compute a new array fahrenheit using the formula F = C * 9 / 5 + 32 applied to the whole celsius array at once — NumPy applies the arithmetic element-by-element automatically.
  4. Print the fahrenheit array.

Here is an example execution.

Celsius temperatures (comma-separated): 0,20,37,100
[ 32.   68.   98.6 212. ]

Note: printing a NumPy array directly (rather than looping over it yourself to call print() on each value) is expected here — that's exactly the output shown above.

Grading

  • 90% — Correctness: Your program should run as specified, using NumPy's element-wise arithmetic rather than a manual loop over the array.
  • 10% — Understandability: Your program should be easy to read.
